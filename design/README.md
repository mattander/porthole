# Layout prototype

`native-ui/index.html` is the original standalone, interactive design mockup.
It uses fictional events, networks and status values and does not connect to
calendar, weather or AI services. Open it locally to explore its sample controls.

Its illustrative AI settings predate the current 400-character native briefing
and waking-hours schedule. Use the [native app documentation](../linux/native/README.md)
and [AI setup guide](../linux/ai/README.md) for current runtime behavior.
