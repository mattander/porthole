# Bundled interface fonts

Unmodified Regular, SemiBold and Bold font files from
[Google Fonts](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/poppins),
revision `8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5`.

Copyright 2020 The Poppins Project Authors. Distributed under the
[SIL Open Font License 1.1](OFL.txt). The app embeds both the fonts and their
licence, available through Settings → Display → Font licences or
`porthole --font-licence`. No font download or system font installation is needed.

Noto Color Emoji is the unmodified COLRv1 font from
[Google's Noto Emoji repository](https://github.com/googlefonts/noto-emoji/tree/1ffdd21391dd1f25c081fa93a9dea0c7c029442b/2D/fonts),
revision `1ffdd21391dd1f25c081fa93a9dea0c7c029442b`.
Copyright 2022 Google Inc. Its [SIL Open Font License](Noto-Emoji-OFL.txt) is
also embedded and shown in the font licences view. The full font includes flag,
skin-tone and joined emoji sequences; it is not a hand-picked glyph subset.
